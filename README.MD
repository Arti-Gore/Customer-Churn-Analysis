# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data to identify patterns and factors that influence customer retention.

## Objectives
- Analyze customer demographics and behavior
- Identify key factors contributing to customer churn
- Calculate overall churn rate
- Compare churn across different customer segments
- Visualize insights using Python

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains customer information including:
- Customer ID
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Internet Service
- Payment Method
- Monthly Charges
- Total Charges
- Churn Status

## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Exploratory Data Analysis (EDA)
- Churn Rate Calculation
- Customer Segmentation
- Data Visualization

## Key Insights
This analysis helps understand which customer groups are more likely to churn and provides insights that can support customer retention strategies.

## Project Files
- `Customer churn analysis.ipynb` - Complete data analysis and visualization notebook
